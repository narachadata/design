글꼴 둘러보기 무료 글꼴 35종 (OFL) + 내 글꼴

사용 방법

기본 사용 Canva처럼 페이지 위에 텍스트·이미지·도형·달력 요소를 올리고 끌어서 배치합니다. 요소를 누르면 오른쪽에서 속성을 고치고, 모서리 손잡이로 크기를, 위쪽 손잡이로 회전을 바꿉니다. 글자는 두 번 눌러 바로 고칩니다.

  1. 캘린더 만들기 왼쪽 메뉴 "나라차 → 캘린더"의 캘린더 마법사에서 연도를 고르고 "26쪽 만들기"를 누르면 표지·12개월 이미지면·12개월 달력면·뒷표지가 만들어집니다. 만들어진 요소는 모두 자유롭게 편집할 수 있습니다.
  2. 공휴일 상단 "공휴일" 버튼에서 연도를 고르고 정보를 가져와야 달력에 표시됩니다(Nager.Date 무료 API, 공공데이터포털 API 키, 또는 내장 표 2023~2036년). 가져온 목록은 직접 고칠 수 있습니다.
  3. 일정 달력 요소를 선택한 뒤 날짜 칸을 누르면 오른쪽에서 일정을 적습니다. "반복 일정 넣기"로 매달 반복되는 승급심사 같은 일정을 한 번에 넣습니다.
  4. 글꼴 기본 한글 글꼴 39종에 요즘 디자이너가 많이 쓰는 무료 인기 글꼴 39종(G마켓 산스·배민 한나·을지로·여기어때 잘난체·에스코어드림·페이퍼로지·어그로체·마루부리 등 한글 33종 + 영문 Bebas Neue·Oswald·Anton·Cinzel·Playfair·Great Vibes, "인기" 표시)이 더해졌습니다. 인기 글꼴은 쓰는 순간에만 불러와 프로그램이 무거워지지 않습니다. 구글 드라이브 자료실의 글꼴(윤고딕·윤명조·태백산맥, "자료실" 표시)은 동기화 폴더가 연결된 PC에서만 보입니다. 상단 "글꼴"에서 고르거나 내 글꼴 파일(.ttf/.otf/.woff2)을 올려 쓸 수 있습니다.
  5. AI "AI 도우미"는 기본으로 내 채팅 요금제를 씁니다: ① 단추로 지시문을 복사하면 Claude·Gemini 채팅이 새 탭에 열리고, 붙여 넣어 보낸 뒤 받은 답·그림을 ② 칸에 붙여 넣습니다(그림은 오른쪽 클릭 → 이미지 복사 → ⌘V·Ctrl+V). "AI 설정"에서 API 키 자동 방식으로 바꿀 수 있습니다(구독과 별도 요금).
  6. 영상 왼쪽 "영상" 메뉴를 누르면 아래에 타임라인이 열립니다(다른 메뉴로 가면 숨음 — "보기 방식"에서 바꿈). 장면=쪽이고 자막·소리는 장면에 붙어 함께 움직입니다(파이널컷 방식). 장면을 고르고 Delete=지우고 당기기, Shift+Delete=빈 틈, Ctrl+B 자르기, 소리 위 흰 선=음량. 동영상·소리 파일은 끌어다 놓으면 원본은 이 PC에만 두고 씁니다. MP4 저장은 Ctrl+E, 단축키 목록은 타임라인의 ? 단추.
  7. 메인 화면 왼쪽 위 로고를 누르면 내 드라이브(내 디자인·새 디자인 만들기)가 열립니다. 다른 문서로 넘어갔다가 되돌아가려면 저장 ▾ → 직전 문서 되살리기.
  8. 저장과 출력 작업은 이 브라우저에 자동 저장됩니다. 구글 드라이브 동기화 폴더를 연결하면 두 PC에서 같은 문서를 씁니다(저장 ▾ → 저장 · 동기화 설정). 파일 한 개로 주고받을 때는 저장 ▾ → 파일로 내려받기 (JSON). 오른쪽 위 다운로드에서 JPG·PNG(크기 1~3배, 여러 쪽은 ZIP 또는 한 장으로 합치기)와 PDF(고화질 300dpi · 가벼운 공유용 200dpi · 인쇄소용 도련·재단선 · 벡터)를 작업한 크기 그대로 바로 받습니다. 글자가 가장 선명한 벡터 PDF가 필요하면 "PDF (벡터 · 인쇄 창)"을 고릅니다. 도련(재단 여유)은 문서 설정에서 넣습니다.

새 기능 왼쪽 메뉴의 "요소"에서 도형·선·아이콘·프레임·앨범 프레임·배지·표·스마트 블록·장식·차트를 골라 넣고, "텍스트"에서 스타일 프리셋으로 글자를 넣습니다. 글자 속성 패널에는 그라데이션·외곽선·그림자·광선·3D·휘기(아치·원형) 효과가, 이미지 속성 패널에는 필터·틴트·모양 마스크·확대/이동과 "편집기"(색 지정 배경 지우기·지우개/복원 브러시·자르기)가 있습니다. 도구 막대의 펜(P)으로 자유 곡선을 그릴 수 있습니다.

단축키 Ctrl+Z 실행 취소(그 쪽으로 돌아가 되돌림), Ctrl+Shift+Z 다시 실행, Ctrl+C·X·V 복사·잘라내기·붙여넣기(그림 포함, 다른 쪽에서는 같은 자리), Ctrl+Shift+V 같은 자리에 붙여넣기, Ctrl+D 복제, Ctrl+G 그룹, Ctrl+]·[ 앞으로·뒤로(Shift: 맨 앞·맨 뒤), Delete 삭제(잠긴 요소 제외), 화살표 1mm 이동(Shift 5mm, Alt 0.1mm), 아무것도 고르지 않았을 때 화살표로 쪽 이동, Ctrl+0 화면 맞춤, Ctrl+1 100%, Ctrl+= / - 확대·축소(마우스 위치 기준은 Ctrl+휠), Space+끌기 화면 이동, T 글 상자, P 펜, Ctrl+B·I·U 굵게·기울임·밑줄, Ctrl+F 찾아 바꾸기(글꼴 한꺼번에 바꾸기 포함), Ctrl+Alt+C·V 스타일 복사·붙여넣기(맥은 Control+Option+C·V), Ctrl+L 잠금, Alt+끌기 복제, Shift+H·V 그림 좌우·상하 뒤집기, 1~9·0 투명도 10~90%·100%, Ctrl+←·→ 1° 회전(Shift 15°), Shift+R 눈금자(눈금자에서 끌어 안내선 만들기, 안내선을 눈금자로 끌면 지움), Alt+A·H·D 왼쪽·가로 가운데·오른쪽 맞춤, Alt+W·V·S 위·세로 가운데·아래 맞춤(하나면 쪽에), Alt+Shift+H·V 가로·세로 같은 간격, Alt 누르고 있기 = 거리 재기(다른 개체 위에 마우스를 올리면 그 개체까지), Ctrl을 누른 채 끌기 = 맞춤 잠깐 끔. 요소나 빈 곳을 오른쪽 클릭하면 메뉴가 열립니다(여러 개면 정렬 그림 · 사진 배치, 그림·도형이면 글 배치).

측정 향상왕 · 출력 상장 → 기록 향상왕 → 📥 관리프로그램 측정에서 향상왕 가져오기에서 연도·전반기/후반기·줄넘기/체력을 고르면 관리프로그램과 같은 방법으로 향상왕(나이 그룹별 향상 1위, 지금 재원생만)을 계산해 명단을 채우고, 한 학생이 여러 종목이면 상장 한 장에 모두 들어갑니다. 맨 위 🖨 출력(Ctrl+P)은 프린터로 바로 찍습니다 — 고화질 그림(화면과 똑같이) 또는 글자 선명(벡터), 꽉 채움(테두리 없음)·프린터 여백 안, 엡손 잉크젯 윈도우·맥 설정 안내.

상장 (메일머지) 왼쪽 메뉴 나라차 → 상장에서 ① 상장 틀(PDF·그림)을 한 번 불러오고 ② 양식(기록 향상왕·급증·일반 상장)과 모두 같은 값(상장 이름·측정 이름·날짜·종목)을 정한 뒤 ③ 명단 표에 이름·기록을 넣거나 엑셀에서 붙여 넣으면 ④ ◀ ▶로 사람마다 미리 보고 ⑤ "상장 N장 만들기"로 한 사람에 한 쪽씩 만들어집니다. 다운로드에서 PDF로 한 번에 저장하고, 틀이 인쇄된 상장 용지에는 "틀도 함께 인쇄"를 끄면 글자만 찍힙니다. 한 쪽에서 글 상자를 옮기거나 글꼴을 바꾼 뒤 "이 쪽 배치를 모든 상장에"를 누르면 모두 같은 배치가 됩니다.

글 상자 글 상자에도 위·아래 가운데 끌기점이 있어 높이를 정할 수 있습니다(그러면 "고정 크기"). 글자 속성의 글 상자에서 자동 너비(한 줄로 늘어남)·자동 높이(기본)·고정 크기를 고르고, 고정 크기에서 글이 넘치면 상자 오른쪽 아래에 빨간 +가 뜹니다(누르면 상자를 글에 맞춤). "글자 크기 자동 맞춤"을 켜면 상자에 맞게 글자 크기가 저절로 줄고 늘며(이름표·상장), 단 나누기(2~4단)·최대 줄 수(넘으면 …)·안쪽 여백도 정합니다. 끌기점을 두 번 누르면 상자가 글에 딱 맞춰집니다.

3차 새 기능 달력 칸을 고르면 뜨는 칸 도구 막대의 📷 사진으로 그 날짜 칸에 사진을 넣습니다(날짜·일정 글은 흰 바탕 위에 그대로). 텍스트 메뉴의 ⏳ D-day 넣기로 "승급심사까지 D-12"를 넣으면 볼 때·내보낼 때 날짜로 저절로 계산됩니다(글 속 {디데이:2027-03-28}·{남은날:2027-03-28}). 글자 속성의 문단 스타일에서 "+ 저장"으로 제목·본문 같은 모양을 이름으로 저장하고 다른 글에 고르면 같은 모양이 되며, 한 글을 고친 뒤 "모두에 반영"하면 모든 쪽의 같은 스타일 글이 함께 바뀝니다(인디자인 단락 스타일).

책자 페이지 메뉴의 📖 책자에서 인디자인처럼 모든 쪽 공통 쪽 번호·머리글·바닥글(표지는 빼고, 펼침면이면 바깥쪽에), 여백·단 안내선, 펼침면 보기, 쪽 이름으로 목차 만들기, 중철 소책자 인쇄 PDF(A4 한 장에 두 쪽, 양면 인쇄 후 반으로 접기)를 씁니다. 글 상자에 {쪽}·{전체쪽}을 쓰면 쪽 번호로 바뀝니다.

도장 정보 · 연간 행사 텍스트 메뉴(또는 프로젝트 메뉴)의 🏠 도장 정보에 전화·주소를 저장하면 템플릿의 010-0000-0000·주소 자리가 자동으로 채워지고, 바뀌면 문서 안에서 한꺼번에 바뀝니다. 프로젝트 → 반복 일정·연간 행사에서 "매년 3/2 개학", "매월 25일 원비"처럼 날짜 규칙을 넣거나 여러 줄을 붙여 넣고, ⭐ 도장 기본 목록으로 저장하면 새 문서·다음 해 달력에 그대로 들어갑니다.

빠른 도구 글자를 고르면 캔버스 위 도구 막대에 글꼴·크기·색·굵게·기울임·밑줄·정렬이 바로 나옵니다(스타일 프리셋·효과는 "스타일 ▸" 또는 오른쪽 패널). "요소" 메뉴 맨 위 ▦ QR로 신청서·밴드·유튜브 주소를 QR 코드로 넣고(고른 뒤 "QR 내용·색 고치기"), 📅 달력으로 한 달 달력 칸을 넣습니다. 달력 속성의 음력 표시로 음력 1일·15일 또는 매일 음력 날짜를 작게 보여 줍니다.

페이지 목록 왼쪽 페이지 목록에서 Ctrl(⌘)+클릭으로 여러 쪽, Shift+클릭으로 이어진 쪽을 고르고, Ctrl+A로 모두 고릅니다. 고른 쪽은 Ctrl+C 복사·Ctrl+X 잘라내기·Ctrl+V 붙여넣기(고른 쪽 뒤에)·Ctrl+D 복제·Delete 삭제·Ctrl+↑↓ 옮기기·F2(또는 두 번 누르기) 이름 바꾸기가 됩니다. 오른쪽 버튼 메뉴에는 쪽 잠그기, 숨기기(다운로드·인쇄에서 빼기), 고른 쪽 다운로드도 있습니다.

편하게 쓰기 왼쪽 페이지 목록과 레이어는 끌어서 순서를 바꿉니다(레이어 이름은 두 번 눌러 바꾸기). 컴퓨터의 사진 파일이나 왼쪽 패널의 그림을 캔버스로 끌어 놓으면 들어가고, 그림 위에 놓으면 자리·크기·자르기는 그대로 두고 그림만 바뀝니다. 색 칸 옆 ▾에서 나라차 브랜드 색·이 문서에 쓰인 색·최근 색·스포이트를 쓰고 "같은 색 모두 바꾸기"로 한 번에 바꿉니다. 맨 위 크기 조정 버튼(또는 오른쪽 속성 패널의 크기 표시)에서 캔버스 크기를 바꾸면 내용을 새 크기에 맞춥니다 — 알맞게 다시 배치·전체 크기 맞추기(잘림 없음)·꽉 채우기(넘치는 곳 잘림)·늘려서 채우기·크기 그대로 중에서 고르고, 기준 위치(9곳)와 쪽마다 미리보기를 확인한 뒤 이 디자인을 바꾸거나 사본으로 만듭니다. 그림·요소를 오른쪽 버튼 → "쪽에 맞추기"·"쪽 꽉 채우기"로 한 번에 맞출 수도 있습니다. 다운로드 창의 인쇄 점검이 안전 여백 밖 글자·작은 글자·흐린 사진을 알려 주고, PNG는 투명 배경과 "선택한 요소만" 저장이 됩니다. 저장 ▾ → 대량 만들기로 명단(엑셀 복사)을 붙여 상장·명찰을 사람 수만큼 한 번에 만들고(글 상자에 {이름}처럼 자리 표시), 버전 기록으로 15분마다 남은 예전 상태를 보고 되돌립니다.

템플릿 위쪽 분류 칩으로 고르고, 들어간 화면은 ‹ 뒤로(Alt+←·마우스 뒤로 단추)로 돌아갑니다. 미리보기의 "만들 크기"에서 문서 형식을 고르면 그 크기에 맞춰 다시 배치됩니다. 명절·휴일 휴관 카드는 다가오는 휴일 날짜가 자동으로 들어갑니다. 큰 동작 뒤 알림의 되돌리기로 바로 원래대로 돌아갈 수 있습니다.
