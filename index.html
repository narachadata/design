사용 방법

기본 사용 Canva처럼 페이지 위에 텍스트·이미지·도형·달력 요소를 올리고 끌어서 배치합니다. 요소를 누르면 오른쪽에서 속성을 고치고, 모서리 손잡이로 크기를, 위쪽 손잡이로 회전을 바꿉니다. 글자는 두 번 눌러 바로 고칩니다.

  1. 캘린더 만들기 왼쪽 "템플릿" 탭의 캘린더 마법사에서 연도를 고르고 "26쪽 만들기"를 누르면 표지·12개월 인성 페이지·12개월 달력 페이지·뒷표지가 만들어집니다. 만들어진 요소는 모두 자유롭게 편집할 수 있습니다.
  2. 공휴일 상단 "공휴일" 버튼에서 연도를 고르고 정보를 가져와야 달력에 표시됩니다(Nager.Date 무료 API, 공공데이터포털 API 키, 또는 내장 표 2023~2030년). 가져온 목록은 직접 고칠 수 있습니다.
  3. 일정 달력 요소를 선택한 뒤 날짜 칸을 누르면 오른쪽에서 일정을 적습니다. "반복 일정 넣기"로 매달 반복되는 승급심사 같은 일정을 한 번에 넣습니다.
  4. 글꼴 무료 한글 글꼴 35종이 들어 있습니다. 상단 "글꼴"에서 미리 보고 고르거나, 내 글꼴 파일(.ttf/.otf/.woff2)을 올려 쓸 수 있습니다.
  5. AI "AI 도우미"에서 Claude에게 인성 문구 초안을 받고, Gemini로 삽화를 만들어 바로 넣을 수 있습니다. API 키는 이 컴퓨터에만 저장됩니다.
  6. 저장과 출력 작업은 이 브라우저에 자동 저장됩니다. 보관·공유는 "저장 (JSON)"으로 파일을 내려받으세요. 오른쪽 위 다운로드에서 JPG·PNG(크기 1~3배, 여러 쪽은 ZIP 또는 한 장으로 합치기)와 PDF(웹용 150dpi·인쇄용 300dpi)를 작업한 크기 그대로 바로 받습니다. 글자가 가장 선명한 벡터 PDF가 필요하면 "PDF (벡터 · 인쇄 창)"을 고릅니다. 도련(재단 여유)은 문서 설정에서 넣습니다.

새 기능 왼쪽 메뉴의 "요소"에서 도형·선·아이콘·프레임·배지·표·스마트 블록·장식·차트를 골라 넣고, "텍스트"에서 스타일 프리셋으로 글자를 넣습니다. 글자 속성 패널에는 그라데이션·외곽선·그림자·광선·3D·휘기(아치·원형) 효과가, 이미지 속성 패널에는 필터·틴트·모양 마스크·확대/이동과 "편집기"(색 지정 배경 지우기·지우개/복원 브러시·자르기)가 있습니다. 도구 막대의 펜(P)으로 자유 곡선을 그릴 수 있습니다.

단축키 Ctrl+Z 실행 취소, Ctrl+Shift+Z 다시 실행, Ctrl+D 복제, Delete 삭제, 화살표 1mm 이동(Shift: 5mm), Ctrl+G 그룹, P 펜, T 글자, Esc 선택 해제, PageUp/Down 페이지 이동.
