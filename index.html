글꼴 둘러보기 무료 글꼴 35종 (OFL) + 내 글꼴

사용 방법

기본 사용 Canva처럼 페이지 위에 텍스트·이미지·도형·달력 요소를 올리고 끌어서 배치합니다. 요소를 누르면 오른쪽에서 속성을 고치고, 모서리 손잡이로 크기를, 위쪽 손잡이로 회전을 바꿉니다. 글자는 두 번 눌러 바로 고칩니다.

  1. 캘린더 만들기 왼쪽 "템플릿" 탭의 캘린더 마법사에서 연도를 고르고 "26쪽 만들기"를 누르면 표지·12개월 인성 페이지·12개월 달력 페이지·뒷표지가 만들어집니다. 만들어진 요소는 모두 자유롭게 편집할 수 있습니다.
  2. 공휴일 상단 "공휴일" 버튼에서 연도를 고르고 정보를 가져와야 달력에 표시됩니다(Nager.Date 무료 API, 공공데이터포털 API 키, 또는 내장 표 2023~2030년). 가져온 목록은 직접 고칠 수 있습니다.
  3. 일정 달력 요소를 선택한 뒤 날짜 칸을 누르면 오른쪽에서 일정을 적습니다. "반복 일정 넣기"로 매달 반복되는 승급심사 같은 일정을 한 번에 넣습니다.
  4. 글꼴 기본 한글 글꼴 39종에 요즘 디자이너가 많이 쓰는 무료 인기 글꼴 39종(G마켓 산스·배민 한나·을지로·여기어때 잘난체·에스코어드림·페이퍼로지·어그로체·마루부리 등 한글 33종 + 영문 Bebas Neue·Oswald·Anton·Cinzel·Playfair·Great Vibes, "인기" 표시)이 더해졌습니다. 인기 글꼴은 쓰는 순간에만 불러와 프로그램이 무거워지지 않습니다. 구글 드라이브 자료실의 글꼴(윤고딕·윤명조·태백산맥, "자료실" 표시)은 동기화 폴더가 연결된 PC에서만 보입니다. 상단 "글꼴"에서 고르거나 내 글꼴 파일(.ttf/.otf/.woff2)을 올려 쓸 수 있습니다.
  5. AI "AI 도우미"에서 Claude에게 인성 문구 초안을 받고, Gemini로 삽화를 만들어 바로 넣을 수 있습니다. API 키는 이 컴퓨터에만 저장됩니다.
  6. 저장과 출력 작업은 이 브라우저에 자동 저장됩니다. 보관·공유는 "저장 (JSON)"으로 파일을 내려받으세요. 오른쪽 위 다운로드에서 JPG·PNG(크기 1~3배, 여러 쪽은 ZIP 또는 한 장으로 합치기)와 PDF(웹용 150dpi·인쇄용 300dpi)를 작업한 크기 그대로 바로 받습니다. 글자가 가장 선명한 벡터 PDF가 필요하면 "PDF (벡터 · 인쇄 창)"을 고릅니다. 도련(재단 여유)은 문서 설정에서 넣습니다.

새 기능 왼쪽 메뉴의 "요소"에서 도형·선·아이콘·프레임·배지·표·스마트 블록·장식·차트를 골라 넣고, "텍스트"에서 스타일 프리셋으로 글자를 넣습니다. 글자 속성 패널에는 그라데이션·외곽선·그림자·광선·3D·휘기(아치·원형) 효과가, 이미지 속성 패널에는 필터·틴트·모양 마스크·확대/이동과 "편집기"(색 지정 배경 지우기·지우개/복원 브러시·자르기)가 있습니다. 도구 막대의 펜(P)으로 자유 곡선을 그릴 수 있습니다.

단축키 Ctrl+Z 실행 취소(그 쪽으로 돌아가 되돌림), Ctrl+Shift+Z 다시 실행, Ctrl+C·X·V 복사·잘라내기·붙여넣기(그림 포함, 다른 쪽에서는 같은 자리), Ctrl+Shift+V 같은 자리에 붙여넣기, Ctrl+D 복제, Ctrl+G 그룹, Ctrl+]·[ 앞으로·뒤로(Shift: 맨 앞·맨 뒤), Delete 삭제(잠긴 요소 제외), 화살표 1mm 이동(Shift 5mm, Alt 0.1mm), 아무것도 고르지 않았을 때 화살표로 쪽 이동, Ctrl+0 화면 맞춤, Ctrl+1 100%, Ctrl+= / - 확대·축소(마우스 위치 기준은 Ctrl+휠), Space+끌기 화면 이동, T 글 상자, P 펜, Ctrl+B·I·U 굵게·기울임·밑줄, Ctrl+F 찾아 바꾸기(글꼴 한꺼번에 바꾸기 포함), Ctrl+Alt+C·V 스타일 복사·붙여넣기(맥은 Control+Option+C·V), Ctrl+L 잠금, Alt+끌기 복제, Shift+H·V 그림 좌우·상하 뒤집기, 1~9·0 투명도 10~90%·100%, Ctrl+←·→ 1° 회전(Shift 15°), Shift+R 눈금자(눈금자에서 끌어 안내선 만들기, 안내선을 눈금자로 끌면 지움). 요소나 빈 곳을 오른쪽 클릭하면 메뉴가 열립니다.

편하게 쓰기 왼쪽 페이지 목록과 레이어는 끌어서 순서를 바꿉니다(레이어 이름은 두 번 눌러 바꾸기). 컴퓨터의 사진 파일이나 왼쪽 패널의 그림을 캔버스로 끌어 놓으면 들어가고, 그림 위에 놓으면 자리·크기·자르기는 그대로 두고 그림만 바뀝니다. 색 칸 옆 ▾에서 나라차 브랜드 색·이 문서에 쓰인 색·최근 색·스포이트를 쓰고 "같은 색 모두 바꾸기"로 한 번에 바꿉니다. 저장 ▾ → "크기 조정"에서 다른 크기로 사본을 만들면 내용이 새 크기에 맞춰 다시 배치됩니다. 다운로드 창의 인쇄 점검이 안전 여백 밖 글자·작은 글자·흐린 사진을 알려 주고, PNG는 투명 배경과 "선택한 요소만" 저장이 됩니다. 저장 ▾ → 대량 만들기로 명단(엑셀 복사)을 붙여 상장·명찰을 사람 수만큼 한 번에 만들고(글 상자에 {이름}처럼 자리 표시), 버전 기록으로 15분마다 남은 예전 상태를 보고 되돌립니다.

템플릿 위쪽 분류 칩으로 고르고, 들어간 화면은 ‹ 뒤로(Alt+←·마우스 뒤로 단추)로 돌아갑니다. 미리보기의 "만들 크기"에서 문서 형식을 고르면 그 크기에 맞춰 다시 배치됩니다. 명절·휴일 휴관 카드는 다가오는 휴일 날짜가 자동으로 들어갑니다. 큰 동작 뒤 알림의 되돌리기로 바로 원래대로 돌아갈 수 있습니다.
