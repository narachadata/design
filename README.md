# 나라차 디자인 공방

Canva·미리캔버스처럼 자유롭게 요소를 배치하는 디자인 에디터이며, 탁상 인성 캘린더(224×154mm, 26쪽) 제작에 특히 맞춰져 있습니다. 설치 없이 `index.html`을 Chrome 또는 Edge에서 열면 됩니다.

## 인터넷 주소
어느 PC에서나 아래 주소를 Chrome·Edge로 열면 바로 쓸 수 있습니다 (첫 실행 때 글꼴을 받으므로 조금 걸립니다).

**https://narachadata.github.io/design/**

여러 PC에서 같은 설정과 문서를 쓰려면 아래 "여러 PC에서 쓰기"처럼 구글 드라이브 폴더를 연결하세요.

## 시작하기
1. `index.html`을 두 번 눌러 엽니다 (Chrome·Edge 권장).
2. 처음 열면 2026년 디자인을 바탕으로 한 **2027년 캘린더 초안 26쪽**이 만들어져 있습니다.
3. 상단 **공휴일**에서 연도를 고르고 정보를 가져와 적용해야 달력에 공휴일이 표시됩니다.
4. 상단 **저장·동기화** → **동기화 폴더 연결**로 구글 드라이브 폴더를 연결해 두면 이후 자동 저장·동기화됩니다.

## 여러 PC에서 쓰기 (구글 드라이브 동기화 폴더)
1. 각 PC에 **Google Drive 데스크톱 앱**을 설치하고 같은 계정으로 로그인합니다.
2. 상단 **저장·동기화 → 동기화 폴더 연결**을 누르고 **내 드라이브 → 나라차디자인공방** 폴더를 고릅니다 (없으면 그 창에서 새로 만듭니다). Windows는 보통 `G:\내 드라이브`, Mac은 Finder 왼쪽 `Google Drive → 내 드라이브`입니다.
3. 그 폴더에 다음이 저장되고, 다른 PC에서 같은 폴더를 연결하면 그대로 이어집니다.
   - `설정.naracha.json` — 설정값: Claude·Gemini API 키와 모델, 이미지 비율·크기, 공공데이터포털 키, 최근 사용 글꼴·요소·템플릿
   - `*.design.json` — 문서들 (올린 이미지·AI 이미지 포함). **새 문서**는 자동으로 이 폴더에 만들어지고, 문서 이름을 바꾸면 파일 이름도 따라 바뀝니다.
4. **열기**를 누르면 폴더 안 문서 목록이 나옵니다. 다른 PC에서 처음 연결하면 가장 최근 문서가 열립니다.
5. 작업 중 다른 PC에서 설정이나 문서가 바뀌면 20초 안에(창으로 돌아올 때는 바로) 알아채 불러옵니다.

### 동시에 작업했을 때 (저장 충돌 방지)
- 저장할 때마다 파일에 저장 번호·저장한 PC 이름·시각을 남기고, **저장 직전에 파일이 다른 PC에서 바뀌었는지 확인**합니다. 바뀌었으면 덮어쓰지 않습니다.
- 다른 PC의 저장이 이 PC의 마지막 저장을 이어받은 것이고 여기 고친 게 없으면 조용히 새 내용을 불러옵니다.
- 두 PC가 같은 문서를 각자 고쳐 갈라졌으면 어느 쪽으로 계속할지 묻고, **고르지 않은 쪽은 같은 폴더에 `문서이름 (충돌 사본 날짜 시각 PC이름).design.json`으로 보관**합니다. 어느 쪽을 골라도 지워지는 내용은 없습니다.
- 문서를 열 때 다른 PC가 5분 안에 저장한 기록이 있으면 "그쪽에서 아직 작업 중일 수 있다"고 알려 줍니다.
- 설정값은 항목별로 합칩니다. 한 PC에서 API 키를, 다른 PC에서 이미지 비율을 동시에 바꿔도 둘 다 남습니다.
- 저장·동기화 창에서 **이 PC 이름**(예: 도장 PC, 집 맥북)을 정해 두면 안내에 그 이름이 나옵니다.
6. PC마다 처음 한 번만 연결하면 됩니다. 브라우저를 다시 열면 상태 표시줄의 **동기화 폴더 연결 (눌러서 허락)** 버튼을 한 번 누르거나, Chrome이 "방문할 때마다 허용"을 물을 때 허용해 두면 됩니다.
- 패널 너비처럼 화면에 따라 다른 값은 PC마다 따로 둡니다.
- API 키가 구글 드라이브 파일에 들어가므로 폴더를 다른 사람과 공유하지 마세요.

## 새 디자인 · 저장 메뉴
- **새 디자인**: 미리캔버스처럼 "무엇을 만들어야 하나요?" 창에서 고릅니다. 추천 · 프레젠테이션 · 소셜 미디어(인스타·스토리·카드뉴스·카카오톡 공지·블로그·밴드) · 유튜브 · 웹 · 인쇄(A4~A2·전단·리플렛·상장·명함·엽서·쿠폰·스티커·명찰) · 문서 · 현수막·배너 · 캘린더 40여 가지 크기와 직접 입력(mm·cm·px)을 지원하고, 검색과 최근 사용 목록이 있습니다. 동기화 폴더가 연결돼 있으면 새 디자인은 바로 그 폴더에 파일로 만들어집니다.
- **저장 (Ctrl+S)**: 파일로 저장합니다. 이후에는 바뀔 때마다 자동 저장됩니다.
- **저장 ▾ 메뉴**: 새 이름으로 저장(Ctrl+Shift+S, 이후 새 파일에서 작업) · 사본 만들기(복제, 폴더에 "○○ 사본" 파일을 만들고 열지 물어봄) · 이름 바꾸기 · 열기(Ctrl+O) · 파일로 내려받기 · 저장·동기화 설정.

## 내 드라이브 (폴더로 정리)
상단 **열기**(Ctrl+O)를 누르면 미리캔버스처럼 **내 드라이브**가 열립니다. 동기화 폴더 안에 하위 폴더를 만들어 디자인을 나눠 담습니다.
- 새 폴더 만들기, 폴더 열기(경로 표시), 상위 폴더로, 전체·폴더·디자인 보기, 수정한 날짜·이름 순, 모든 폴더 검색, 최근 디자인
- 디자인 카드에 첫 쪽 미리보기와 쪽수가 보이고, 지금 작업 중인 디자인은 초록 테두리로 표시됩니다.
- ⋯ 메뉴: 열기 · 이름 바꾸기 · 사본 만들기 · 다른 폴더로 이동 · 휴지통으로. 디자인을 끌어 폴더 위에 놓아도 옮겨집니다.
- 휴지통: 되살리기(내 드라이브 맨 위로) · 영구 삭제 · 휴지통 비우기. 작업 중인 디자인은 휴지통으로 보낼 수 없습니다.
- 폴더 안에서 "새 디자인 만들기"를 누르면 새 디자인이 그 폴더에 저장됩니다. 폴더는 구글 드라이브의 실제 폴더라 두 PC에서 똑같이 보입니다.

## 다운로드
오른쪽 위 **다운로드** 패널에서 고릅니다.
- **PDF (고화질)** 300dpi(권장) · **PDF (가벼운 공유용)** 200dpi · **PDF (인쇄소용)** 300dpi 무손실 + 도련, 재단선을 켜면 도련 바깥 5mm 여백에 0.25pt 선과 TrimBox·BleedBox 정보: 인쇄 창 없이 **작업한 크기 그대로** 바로 받습니다 (예: 탁상 캘린더 224×154mm, 인스타 1080px).
- **JPG** · **PNG**: 크기 1배(화면용 96dpi) · 2배 · 3배(인쇄 가능 288dpi), 여러 쪽은 ZIP으로 묶거나 "한 장의 이미지로 합치기"
- **PDF (벡터 · 인쇄 창)**: 글자가 가장 선명한 벡터 PDF가 필요할 때 브라우저 인쇄 창으로 저장합니다.
- 페이지 선택: 모든 페이지 · 현재 페이지 · 직접 입력(예: 1-3, 5). 현수막처럼 아주 큰 문서는 브라우저 한계 안에서 해상도를 자동으로 낮추고 패널에 표시합니다.

## 캘린더 기능
- **템플릿 탭 → 캘린더 마법사**: 연도를 고르고 전체 26쪽 / 월간 달력 12쪽 / 인성 페이지 12쪽을 만듭니다. 만들어진 요소는 모두 자유롭게 편집할 수 있습니다.
- **달력 요소**: 어느 문서에나 넣을 수 있는 월간 달력·미니 달력. 주 시작 요일, 줄 수, 요일 표기, 색, 글꼴, 선 두께를 바꿀 수 있습니다.
- **일정**: 달력 요소를 선택한 뒤 날짜 칸을 누르고 일정을 적습니다. **반복 일정 규칙**(예: 마지막 월·화요일 정기승급심사)을 한 번에 넣을 수 있습니다.
- **공휴일 자동 적용**: 연도를 고르면 2023~2036년은 자동으로 계산되어 들어갑니다. 양력 공휴일(신정·삼일절·어린이날·현충일·광복절·개천절·한글날·크리스마스, 2027년부터 노동절·제헌절) + 음력 명절(설·추석 연휴, 부처님오신날; 한국천문연구원 자료로 확인한 양력 날짜) + 대체공휴일 규칙(설·추석은 일요일/다른 공휴일과 겹칠 때, 그 밖은 토·일요일/다른 공휴일과 겹칠 때 다음 평일) + 국회의원·지방선거일. 임시공휴일·대통령 선거일은 공휴일 창에서 직접 추가합니다. 공공데이터포털 API(서비스 키)와 Nager.Date도 출처로 고를 수 있습니다.
- **달력 테마 8종**: 클래식 옐로(2026 원형)·네이비 밴드·파스텔 민트·모던 화이트·포토 스플릿·레드 다이내믹·숲 그린·블랙 골드. 레이아웃 4종(클래식·밴드·미니멀·포토)에 색·글꼴이 조합되어 있으며, 마법사나 템플릿 갤러리에서 고르면 26쪽 전체에 적용됩니다. 이미 만든 캘린더에 적용하면 문구·일정·그림은 그대로 두고 디자인만 바뀝니다.
- **AI 도우미**: Claude가 덕목별 명언·실천 과제·사자성어 초안을 만들고(달별 또는 12개월 일괄), Gemini가 삽화를 만듭니다. 적용하면 해당 달의 역할이 지정된 글 상자가 함께 바뀝니다. 흰 배경 자동 제거를 지원합니다.

## 화면 구성 (미리캔버스식)
왼쪽 아이콘 메뉴: 페이지 · 템플릿 · 요소 · 텍스트 · 사진 · 업로드 · 프로젝트 · AI 도구 · 배경 · 테마 · 차트 · 레이어. 패널과 속성 창의 경계를 끌어 너비를 바꿀 수 있습니다.

## 요소 라이브러리

## 글자 효과 (포토샵 레이어 스타일)

## 달력 칸 편집 (일러스트레이터 표처럼)
달력을 고른 상태에서:
- 칸을 누르거나 끌면 칸이 골라지고, 위에 **칸 도구**가 뜹니다: 칸 색 · 칸 색 없애기 · 글자 색 · 크기 −/+ · 굵게 · 정렬 · **합치기 · 나누기** · 열 같게 · 행 같게 · 입력 · 지우기.
- Shift+누르기 / Shift+화살표로 범위를 넓히고, 화살표로 칸을 옮겨 다닙니다.
- 칸을 **두 번 누르거나 Enter, 또는 바로 타자**를 치면 칸 안에서 바로 입력합니다. 날짜 칸은 그날 일정(한 줄에 하나), 빈 칸은 자유 글자. Ctrl+Enter로 마치고 Esc로 취소.
- 칸 **경계선을 끌면** 열 너비·행 높이가 바뀌고, 경계선을 두 번 누르면 모두 같게 됩니다. 합친 칸에는 안에 들어간 날짜·일정이 그대로 함께 보입니다.
- 달력 전체를 옮길 때는 요일 줄을 끕니다. Delete는 고른 칸의 글자·서식만 지웁니다.

## 효과 조절
글자·이미지·도형 효과는 숫자 대신 직관적인 장치로 조절합니다. 양·두께·번짐·크기·간격·투명도는 **슬라이더 + 숫자 칸**(투명도류는 %로 표시, 이름을 두 번 누르면 기본값), 회전·그라데이션 방향은 **방향 다이얼**(끌기, Shift로 15° 단위, 0·45·90° 빠른 버튼), 그림자·3D 입체의 위치는 **위치 패드**(점을 끌어 놓기, 아래·오른쪽 아래 등 빠른 버튼)를 씁니다. 그림자는 "부드럽게·또렷하게·강하게·떠 있게" 빠른 설정도 있습니다. 위치·크기(X·Y·너비·높이)는 정확한 값을 넣도록 숫자 칸을 그대로 둡니다.

## 미리캔버스·캔바에서 가져온 기능
- **찾아 바꾸기 (Ctrl+F)**: 글 상자·달력 일정·메모·칸 글자까지 모든 쪽에서 찾아 하나씩 또는 모두 바꿉니다(예: 2027→2028). 잠긴 요소는 바꾸지 않습니다. 같은 창에서 글꼴을 문서 전체에서 한꺼번에 바꿉니다.
- **스타일 복사·붙여넣기**: 한 제목의 글꼴·색·외곽선·그림자·3D 효과를 다른 글자에 그대로 옮깁니다(위치·회전·자르기는 옮기지 않음).
- **오른쪽 클릭 메뉴**: 복사·잘라내기·붙여넣기·복제·삭제·스타일·순서·그룹·잠금·뒤집기·배경으로 만들기.
- **쪽 모아 보기** (페이지 패널 → 모아 보기): 모든 쪽을 한눈에 보고, Ctrl/⌘·Shift로 여러 쪽을 골라 복제·삭제하거나 끌어서 한꺼번에 옮깁니다. 두 번 누르면 그 쪽으로 갑니다.
- **끌어서 순서 바꾸기**: 페이지 목록과 레이어. 레이어 이름은 두 번 눌러 바꿉니다.
- **사진 끌어 넣기·교체**: 컴퓨터 파일이나 왼쪽 패널 그림을 캔버스로 끌어 놓습니다. 그림 위에 놓으면 자리·크기·자르기는 그대로 두고 그림만 바뀝니다.
- **색 고르기**: 색 칸 옆 HEX 입력과 ▾ 팔레트(나라차 브랜드 색 · 이 문서에 쓰인 색 · 최근 색 · 기본 색 · 스포이트). "같은 색 모두 바꾸기"로 이 쪽 또는 모든 쪽의 같은 색을 한 번에 바꿉니다. 브랜드 색은 동기화되어 다른 PC에서도 같습니다.
- **크기 조정** (저장 ▾ 또는 프로젝트 탭): 새 크기를 고르면 미리보기를 보며 "알맞게 다시 배치(가장자리 요소는 가장자리에, 배경·띠는 꽉 채움) / 늘려서 채우기 / 내용 크기 그대로" 중에서 고르고, 이 디자인을 바꾸거나 **다른 크기로 사본**을 만듭니다(예: A3 포스터 → 인스타 4:5).
- **인쇄 점검**: 인쇄용 다운로드 창에서 안전 여백(3mm) 밖 글자, 6pt 미만 글자, 흐린 사진, 도련까지 안 닿은 가장자리 도형을 쪽 번호와 함께 알려 주고, 이름을 누르면 그 요소로 갑니다.
- **대량 만들기** (저장 ▾): 상장·승급증·명찰을 명단으로 한 번에. 글 상자에 `{이름}`·`{띠}`처럼 자리를 적어 두고, 엑셀·구글 시트에서 첫 줄(열 이름)까지 복사해 붙이면 사람 수만큼 쪽이 문서 끝에 생깁니다(최대 300명). 자리를 안 적은 열은 글 상자를 골라 연결할 수 있습니다.
- **버전 기록** (저장 ▾): 동기화 폴더에 저장되는 문서는 15분마다 상태가 `.기록` 폴더에 남습니다(문서마다 최근 40개, 내 드라이브 목록에는 안 보임). 시간·PC별로 미리 보고 되돌리거나 사본으로 만들 수 있고, 되돌리기 직전 상태도 자동으로 남깁니다.
- **템플릿 바로 적용**: 빈 쪽에서 템플릿을 고르면 "이 쪽에 적용"으로 그 쪽에 바로 들어가고, 문서 크기가 다르면 크기 조정 규칙으로 맞춰 배치합니다.
- **투명 배경 PNG·선택한 요소만 내려받기**: PNG에서 쪽 배경을 빼거나, 고른 요소만 잘라 저장합니다(로고·스티커·엠블럼용).

## 편집 동작 (전문 편집 툴 기준)
- **눈금자·안내선 (Shift+R)**: mm 눈금자에 고른 요소의 범위가 파랗게 표시됩니다. 눈금자에서 끌어 내리면 안내선이 생기고(요소 가장자리·가운데에 붙음, Alt로 끄기), 끌어 옮기거나 눈금자로 되돌리면 지워집니다. 안내선은 문서에 저장되고 자석 정렬 대상입니다. 빈 곳 오른쪽 클릭 → 안내선 모두 지우기.
- **형식별 안내선**: 인스타 스토리는 위·아래 가림 영역, 3단 리플렛은 접는 선(99·198mm), 유튜브 썸네일은 재생 시간 자리, 현수막·X배너는 넓은 안전 여백(30~40mm)을 보여 주고 자석 정렬도 안전 여백 선에 붙습니다.
- 그림의 너비·높이를 숫자로 바꾸면 비율이 유지됩니다(속성 창의 '비율 고정'으로 끄기). Ctrl+G는 늘 묶기, Ctrl+Shift+G는 풀기. 끌던 중 Esc는 원래 자리로. 여러 개 고른 상태에서 하나를 누르면 그것만 골라집니다.
- 다른 프로그램에서 복사한 화면 캡처·사진은 Ctrl+V로 바로 들어오고, 글자는 새 글 상자로 들어옵니다. 내용을 모두 지운 글 상자는 편집을 마칠 때 사라집니다.
- 한글은 낱말 단위로 줄이 바뀝니다. 굵기 목록에는 그 글꼴에 실제로 있는 굵기만 나옵니다(없는 굵기는 '가짜 굵게' 표시).
- 정렬·간격 맞추기는 그룹을 한 덩어리로 다루고, 잠긴 요소는 움직이지 않습니다. 하나(또는 그룹 하나)만 고르면 페이지 기준으로 정렬합니다.
- 여러 요소를 고르면 모서리 핸들로 함께 크기를 바꿉니다(글자 크기·선 두께도 비율대로). Shift+드래그는 선택에 더합니다.
- 여러 요소를 고르면 속성 창에 **묶음 위치·크기(X·Y·너비·높이)** 칸이 나와 정확한 값으로 옮기거나 비율대로 키울 수 있습니다.
- 도련이 있는 문서는 **인쇄 안내선**이 보입니다: 빨간 점선=도련(배경을 여기까지), 파란 점선=안전 여백 3mm(글자·로고는 안쪽에). 프로젝트 탭에서 끌 수 있습니다.
- 다운로드 창은 인쇄 크기에 비해 해상도가 낮은 사진(보통 150ppi, 현수막 60ppi 미만)을 알려 줍니다.
- 잠긴 요소는 캔버스에서 클릭이 통과합니다(배경을 잠가 두면 그 위에서 드래그 선택 가능). 레이어 목록에서 고를 수 있습니다.
- 글 상자는 위쪽 정렬일 때 내용에 맞게 높이가 늘고 줄어듭니다. 붙여넣기는 글자만 들어옵니다.
- 회전된 요소도 크기를 바꿀 때 반대쪽 모서리가 제자리에 있습니다. 자석(스냅)은 화면 기준 6px 거리입니다.
- 달력 칸 색·글자는 날짜에 붙어 있어 달·주 시작을 바꿔도 그 날짜를 따라갑니다. 테마를 바꿔도 칸 서식과 직접 넣은 요소는 유지됩니다.
