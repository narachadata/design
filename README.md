# 나라차 디자인 공방

Canva·미리캔버스처럼 자유롭게 요소를 배치하는 디자인 에디터이며, 탁상 인성 캘린더(224×154mm, 26쪽) 제작에 특히 맞춰져 있습니다. 설치 없이 `index.html`을 Chrome 또는 Edge에서 열면 됩니다.

## 인터넷 주소
어느 PC에서나 아래 주소를 Chrome·Edge로 열면 바로 쓸 수 있습니다 (첫 실행 때 글꼴을 받으므로 조금 걸립니다).

**https://narachadata.github.io/design/**

작업 문서는 각 PC의 브라우저에 따로 저장되므로, 여러 PC에서 같은 문서를 이어서 쓰려면 "저장·동기화 → 파일에 연결"로 동기화 폴더(Google Drive 등)의 파일에 연결하세요.

## 시작하기
1. `index.html`을 두 번 눌러 엽니다 (Chrome·Edge 권장).
2. 처음 열면 2026년 디자인을 바탕으로 한 **2027년 캘린더 초안 26쪽**이 만들어져 있습니다.
3. 상단 **공휴일**에서 연도를 고르고 정보를 가져와 적용해야 달력에 공휴일이 표시됩니다.
4. 상단 **저장·동기화** → **파일에 연결**로 문서 파일을 만들어 두면 이후 자동 저장됩니다.

## 여러 PC에서 쓰기
- 문서 파일(`*.design.json`)을 Google Drive·OneDrive·Dropbox·NAS 같은 **동기화 폴더**에 저장하세요.
- 다른 PC에서는 **열기**로 같은 파일을 열면 이어서 작업할 수 있고, 작업 중 다른 PC에서 파일이 바뀌면 자동으로 알아채 불러옵니다.
- 이 프로그램 폴더 전체를 같은 동기화 폴더에 두면 모든 PC에서 같은 프로그램을 바로 열 수 있습니다.
- 문서 파일에는 올린 이미지·AI 이미지가 함께 저장됩니다. 글꼴과 2026 삽화는 프로그램 폴더에 들어 있습니다.

## 캘린더 기능
- **템플릿 탭 → 캘린더 마법사**: 연도를 고르고 전체 26쪽 / 월간 달력 12쪽 / 인성 페이지 12쪽을 만듭니다. 만들어진 요소는 모두 자유롭게 편집할 수 있습니다.
- **달력 요소**: 어느 문서에나 넣을 수 있는 월간 달력·미니 달력. 주 시작 요일, 줄 수, 요일 표기, 색, 글꼴, 선 두께를 바꿀 수 있습니다.
- **일정**: 달력 요소를 선택한 뒤 날짜 칸을 누르고 일정을 적습니다. **반복 일정 규칙**(예: 마지막 월·화요일 정기승급심사)을 한 번에 넣을 수 있습니다.
- **공휴일 자동 적용**: 연도를 고르면 2023~2036년은 자동으로 계산되어 들어갑니다. 양력 공휴일(신정·삼일절·어린이날·현충일·광복절·개천절·한글날·크리스마스, 2027년부터 노동절·제헌절) + 음력 명절(설·추석 연휴, 부처님오신날; 한국천문연구원 자료로 확인한 양력 날짜) + 대체공휴일 규칙(설·추석은 일요일/다른 공휴일과 겹칠 때, 그 밖은 토·일요일/다른 공휴일과 겹칠 때 다음 평일) + 국회의원·지방선거일. 임시공휴일·대통령 선거일은 공휴일 창에서 직접 추가합니다. 공공데이터포털 API(서비스 키)와 Nager.Date도 출처로 고를 수 있습니다.
- **달력 테마 8종**: 클래식 옐로(2026 원형)·네이비 밴드·파스텔 민트·모던 화이트·포토 스플릿·레드 다이내믹·숲 그린·블랙 골드. 레이아웃 4종(클래식·밴드·미니멀·포토)에 색·글꼴이 조합되어 있으며, 마법사나 템플릿 갤러리에서 고르면 26쪽 전체에 적용됩니다. 이미 만든 캘린더에 적용하면 문구·일정·그림은 그대로 두고 디자인만 바뀝니다.
- **AI 도우미**: Claude가 덕목별 명언·실천 과제·사자성어 초안을 만들고(달별 또는 12개월 일괄), Gemini가 삽화를 만듭니다. 적용하면 해당 달의 역할이 지정된 글 상자가 함께 바뀝니다. 흰 배경 자동 제거를 지원합니다.

## 화면 구성 (미리캔버스식)
왼쪽 아이콘 메뉴: 페이지 · 템플릿 · 요소 · 텍스트 · 사진 · 업로드 · 프로젝트 · AI 도구 · 배경 · 테마 · 차트 · 레이어. 패널과 속성 창의 경계를 끌어 너비를 바꿀 수 있습니다.

## 요소 라이브러리
"요소" 메뉴에서 검색·분류(일러스트·도형·선·아이콘·프레임·배지·표·스마트 블록·장식·차트)로 골라 넣습니다. 도형 15종×스타일 6종, 선 13종, 아이콘(이모지) 110여 개, 프레임 6종, 배지 10종, 표·목록 6종, 스마트 블록 8종, 장식 9종, 차트 5종. 여러 조각으로 된 요소는 자동으로 그룹이 됩니다(Ctrl+G 묶기/해제). 최근 사용 요소가 맨 위에 나옵니다.

## 글자 효과 (포토샵 레이어 스타일)
단색·그라데이션 채우기, 외곽선, 그림자, 광선, 3D 입체·긴 그림자, 휘기(아치·원형), 밑줄·취소선·대문자·세로쓰기, 혼합 모드, 상자 배경. 스타일 프리셋 14종을 한 번에 적용할 수 있고, 글꼴 선택 목록은 각 글꼴 모양으로 보이며 최근 사용한 글꼴 3개가 맨 위에 옵니다.

## 이미지·일러스트
필터(밝기·대비·채도·색조·흐림·흑백·세피아·반전, 프리셋 8종), 색 입히기(틴트), 모양 마스크(원·둥근·별·육각·하트 등), 확대/이동 프레이밍, 테두리·그림자, 혼합 모드. 벡터 도형은 그라데이션·점선·화살표·꼭짓점 수를 바꿀 수 있고, 펜(P)으로 자유 곡선을 그립니다.

## 이미지 편집기 (배경 지우기)
이미지 속성의 "편집기"에서: 스포이트로 지울 색을 고르고 허용 범위·가장자리 부드러움을 조절해 지웁니다. "바깥에서 이어진 영역만" 옵션으로 안쪽 같은 색은 보존하고, 가장자리 색 번짐 제거·작은 조각 제거·가장자리 매끈하게로 깔끔한 결과를 만듭니다. 지우개·복원 브러시(크기·경도)로 세밀하게 다듬고, 자르기도 됩니다. AI 이미지의 흰 배경도 같은 엔진으로 자동 제거됩니다.

## 자동 업데이트
프로그램이 새로 올라오면 열려 있는 창이 1분 안에 알아채고, 편집 중이 아닐 때 10초 예고 후 스스로 새로고침합니다. 배포는 `./deploy.sh "설명"` 한 줄로 합니다(버전 파일 갱신 → 커밋 → 푸시 → 반영 확인).

## 템플릿 찾기 (미리캔버스식)
템플릿 패널은 검색창과 다섯 가지 필터(제작 형태 · 계절 · 연령 · 상황 · 직종)로 215장을 찾습니다. 검색어는 "가을 모집 포스터", "유아", "카페 오픈"처럼 여러 단어를 띄어 써도 됩니다. 필터가 없을 때는 최근 사용 · 이 계절 추천 · 달력 테마 · 모집 · 행사·축하 · 명절·감사 · 다른 직종 · SNS · 포스터 · 안내문 줄로 보여 주며, 미리보기는 화면에 보일 때만 그려 가볍습니다.

생성형 템플릿 100여 장은 계절 팔레트(봄·여름·가을·겨울·사계절), 연령 톤(유아·초등·청소년·성인·학부모), 상황 카피(모집·행사·축하·안내·명절·감사·할인·오픈·심사·캠프·휴관·교육), 직종(태권도장·학원·유치원·교회·카페·미용실·헬스·병원·부동산·소상공인·학교)을 레이아웃 6종(띠·중앙·분할·액자·미니멀·현수막)에 조합해 만들었습니다.

## 범용 템플릿 28종 + 색상 변형
템플릿 탭의 갤러리에서 분류별로 고릅니다. 포스터 5종(모집 옐로·모집 네이비·승급심사·품새 대회·겨울 특강), 전단지 3종(캠프·무료 체험·수강 안내), SNS 6종(공지·이벤트·승급 축하·카드뉴스 표지·모집·스토리), 상장·증서 4종(상장·승급증·수료증·개근상), 명함·카드 4종(명함 2종·초대장·생일 카드), 안내문 4종(가정통신문·시간표·차량 노선·안전 수칙), 현수막 2종(모집·입상 축하). 모두 도장 로고·마스코트·삽화가 들어 있고, 전화번호·주소 자리는 비워 두었습니다.

## 글꼴
`fonts/` 폴더에 무료 글꼴 39종(OFL 등)이 들어 있어 상업 인쇄물에 무료로 쓸 수 있습니다(목록과 출처: `fonts/LICENSES.md`). 상단 **글꼴**에서 미리 보고 고르거나, 내 글꼴 파일(.ttf/.otf/.woff2)을 올려 문서에 포함할 수 있습니다.

## 출력
- **PDF 내보내기**: 인쇄 창에서 *대상: PDF로 저장*, *여백: 없음*, *배경 그래픽: 켬*. 용지 크기는 문서 크기(+도련)로 자동 설정됩니다. 인쇄소 납품 시 템플릿 탭의 인쇄 설정에서 도련 3mm와 재단선을 켜세요. 가장자리에 닿은 배경·도형·그림은 도련까지 자동으로 늘어납니다.
- **PNG**: 현재 페이지를 300dpi PNG로 저장합니다 (처음 한 번 인터넷에서 모듈을 받습니다).

- `storage.js` 자동 저장·파일 연결·변경 감지

- `assets.js`, `assets/` 2026 캘린더에서 추출한 삽화·마스코트·로고(투명 PNG)
- `fonts/` 무료 글꼴
